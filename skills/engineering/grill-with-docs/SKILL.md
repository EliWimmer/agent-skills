Run a `/grilling` session, using the `/domain-modeling` skill.

Before each question, check whether the project already answers it. Look in the domain docs (glossary, ADRs, context docs), the implementation, and precedent in similar code. If you find the answer, don't ask. State it, cite where it came from, and move on.

Only ask me when the project is silent, when its sources contradict each other, or when the question is a decision nobody has made yet. When you do ask, name what you checked.
