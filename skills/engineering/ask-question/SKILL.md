# Ask Question

Keep this investigation read-only. Answer the question first; don't change files or implement fixes unless the user subsequently asks.

Trace the current implementation far enough to explain the behavior in question, following relevant callers, data flow, and branches. Base the answer on the code you inspected, and state any uncertainty or gaps in the evidence.

Lead with the direct answer, then show the relevant code excerpts with file and line references. Explain how those excerpts produce the behavior. Keep the trace focused on what the user asked.
